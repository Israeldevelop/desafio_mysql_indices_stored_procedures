# Desafio MySQL — Índices e Stored Procedures

## Objetivo

Desenvolver conhecimentos práticos em SQL e MySQL por meio da criação de consultas, índices e stored procedures para manipulação de dados.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## Estrutura do projeto

| Arquivo | Descrição |
|---|---|
| `Procedure_universidade.sql` | Procedures para manipulação de dados de pessoas e departamentos. |
| `procedure_ecommerce.sql` | Procedure para operações de inserção, atualização e exclusão de clientes. |
| `indices_company.sql` | Consultas SQL, criação de índices e análise do plano de execução. |

## Conceitos praticados

- Stored procedures.
- Parâmetros de entrada (`IN`).
- Estruturas condicionais (`CASE`).
- Operações `INSERT`, `UPDATE` e `DELETE`.
- Consultas com `JOIN`, `LEFT JOIN`, `COUNT`, `GROUP BY` e `ORDER BY`.
- Criação de índices com `CREATE INDEX`.
- Análise de consultas com `EXPLAIN`.

## Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Abra os arquivos `.sql` no MySQL Workbench.
3. Confira se os bancos e as tabelas necessários existem.
4. Execute os scripts na ordem adequada para cada banco de dados.

**Atenção:** alguns scripts criam objetos e inserem dados de exemplo. Confira o conteúdo antes de executá-los novamente em um banco que já contenha dados.

## Aprendizados

O projeto permitiu praticar manipulação de dados, criação e execução de stored procedures, consultas relacionais e utilização de índices para auxiliar no desempenho das consultas SQL.
