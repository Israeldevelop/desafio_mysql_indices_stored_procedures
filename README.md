# Desafio MySQL — Índices e Stored Procedures

## Objetivo
Praticar conceitos de SQL e programação no MySQL por meio de consultas, índices e stored procedures.

## Tecnologias utilizadas
- MySQL
- MySQL Workbench
- SQL

## Conteúdo do projeto
- Stored procedures para manipulação de dados.
- Operações de inserção (`INSERT`), atualização (`UPDATE`) e exclusão (`DELETE`).
- Parâmetros de entrada (`IN`) e estruturas condicionais (`CASE`).
- Consultas e índices SQL, conforme o escopo do desafio.

## Aprendizados
Prática de manipulação de dados, criação e execução de stored procedures e utilização de comandos SQL.
